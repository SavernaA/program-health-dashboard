# iOS 20 Release Program — RACI Matrix

**R** = Responsible (does the work)  
**A** = Accountable (owns the outcome)  
**C** = Consulted (input required)  
**I** = Informed (kept up to date)

---

| Activity | EPM | Eng Directors | Eng Leads | QA Lead | Design Lead | VP Eng |
|---|---|---|---|---|---|---|
| Program kickoff and planning | A | C | R | C | C | I |
| Milestone plan creation | R/A | C | C | C | C | I |
| Weekly status reporting | R/A | I | I | I | I | I |
| Risk identification | R | C | C | C | C | I |
| Risk escalation decisions | A | R | C | — | — | C |
| Convergence gate sign-off | A | C | R | R | C | I |
| Feature scope decisions | C | A | R | C | R | C |
| Resource allocation | C | A | R | C | C | C |
| Executive release readiness review | R | R | C | C | C | A |
| Public release approval | I | C | C | C | C | A |
| Accessibility audit | C | I | R | R | C | I |
| Device validation sign-off | C | I | C | R/A | — | I |
| Performance benchmarks | C | I | R | C | — | I |
| Cross-functional alignment | R/A | C | C | C | C | I |
| Blocker escalation to VP | R/A | C | I | I | I | — |

---

## Notes

- The EPM is accountable for program health visibility at all times — not for individual engineering decisions
- Engineering Leads are responsible for their team's milestone execution; EPM facilitates and removes blockers
- VP Engineering is the final decision-maker on release approval and any scope changes that affect the ship date
- Design Lead is consulted on convergence decisions that affect user-facing behavior
